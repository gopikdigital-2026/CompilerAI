# Identity

The Identity module manages the set of actors and resources that participate in the
security model — users, organizations, AI agents, connectors, and skills. Every
authentication and authorization decision is anchored to an identity.

## Identity types

`@compilerai/security-governance` recognizes 5 identity types:

| Type | Description |
|------|-------------|
| `user` | A human user with login credentials and assigned roles |
| `organization` | An organizational tenant that scopes resources and identities |
| `ai_agent` | An autonomous AI agent identity with execution capabilities |
| `connector` | An integration connector identity for external systems |
| `skill` | A marketplace skill identity representing an installable capability |

Each identity carries a lifecycle status: `active`, `suspended`, or `deactivated`. Only
identities with `active` status can be authenticated.

## Identity fields

```typescript
interface Identity {
  id: string;                 // generated id: id-<counter>-<timestamp>
  type: IdentityType;         // 'user' | 'organization' | 'ai_agent' | 'connector' | 'skill'
  organizationId: string;     // tenant scope for this identity
  status: IdentityStatus;     // 'active' | 'suspended' | 'deactivated'
  ownerId?: string;           // optional owning identity (e.g. agent owner)
  name: string;               // display name
  email?: string;             // optional contact email
  createdAt: string;          // ISO timestamp
  metadata: Record<string, unknown>; // free-form attributes
}
```

The `id` is generated by `generateIdentityId()` and is unique within the manager
instance. The `organizationId` scopes the identity to a tenant; identities are
secondarily indexed by organization so that `list(organizationId)` is efficient.

## CRUD operations

`IdentityManager` exposes the following operations:

| Method | Description |
|--------|-------------|
| `create(type, name, organizationId, options?)` | Creates and stores a new identity |
| `get(id)` | Retrieves an identity by id |
| `update(id, updates)` | Merges partial updates (id, createdAt, organizationId immutable) |
| `delete(id)` | Removes an identity and its org index entry |
| `list(organizationId?)` | Lists all identities or those in an organization |
| `listByType(type, organizationId?)` | Lists identities filtered by type |
| `setStatus(id, status)` | Convenience wrapper around `update` for status changes |
| `exists(id)` | Boolean existence check |
| `count()` | Total identity count |

The `create` options object accepts `email`, `ownerId`, `status` (defaults to
`active`), and `metadata` (defaults to `{}`). The `update` method preserves `id`,
`createdAt`, and `organizationId` against accidental overwrite.

## Code example

```typescript
import { SecurityGovernance } from '@compilerai/security-governance';

const sg = new SecurityGovernance();

// Create a user
const alice = sg.createIdentity('user', 'Alice Chen', 'org-1', {
  email: 'alice@compiler.ai',
  metadata: { department: 'engineering', title: 'Staff Engineer' },
});
console.log(alice.id);            // 'id-1-l...'
console.log(alice.status);        // 'active'
console.log(alice.metadata);      // { department: 'engineering', title: 'Staff Engineer' }

// Create an AI agent owned by Alice
const agent = sg.createIdentity('ai_agent', 'doc-summarizer', 'org-1', {
  ownerId: alice.id,
  metadata: { model: 'gpt-4o' },
});

// List all users in org-1
const users = sg.identity.listByType('user', 'org-1');

// Suspend an identity
const suspended = sg.setIdentities(agent.id, 'suspended');
console.log(suspended?.status);   // 'suspended'

// Direct manager access
const found = sg.identity.get(alice.id);
const orgCount = sg.identity.count();
```
