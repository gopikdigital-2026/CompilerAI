# Ingestion

## Content Sources

The RAG Engine supports four content sources, each identified by a string literal and backed by a dedicated adapter:

| Source | Identifier | Adapter class |
|--------|------------|---------------|
| Google Drive | `google_drive` | `GoogleDriveAdapter` |
| Gmail | `gmail` | `GmailAdapter` |
| GitHub | `github` | `GitHubAdapter` |
| Knowledge Graph | `knowledge_graph` | `KnowledgeGraphAdapter` |

## Source Adapters

Each adapter implements the `IngestionSourceAdapter` interface:

```typescript
interface IngestionSourceAdapter {
  source: ContentSource;
  fetch(since?: string): IngestedDocument[];
}
```

Adapters are registerable on the `IngestionEngine` and support incremental fetches via the optional `since` parameter, which filters documents by `ingestedAt` timestamp.

```typescript
import { IngestionEngine, GoogleDriveAdapter, createDocument } from '@compilerai/enterprise-rag';

const ingestion = new IngestionEngine();
const drive = new GoogleDriveAdapter();

drive.addDocument(createDocument('google_drive', 'file-1', 'Q3 Roadmap', '...', 'alice', 'org-1'));
ingestion.registerAdapter(drive);

// Full fetch
const all = ingestion.ingestFromSource('google_drive');

// Incremental fetch since a timestamp
const recent = ingestion.ingestFromSource('google_drive', '2024-01-01T00:00:00.000Z');
```

## Document Model

The `IngestedDocument` interface captures full provenance for every ingested document:

| Field | Type | Description |
|-------|------|-------------|
| `id` | `string` | Unique document identifier (auto-generated by `createDocument`) |
| `source` | `ContentSource` | Origin source (`google_drive`, `gmail`, `github`, `knowledge_graph`) |
| `sourceId` | `string` | Identifier within the source system |
| `title` | `string` | Document title |
| `content` | `string` | Full text content |
| `author` | `string` | Author identifier |
| `organizationId` | `string` | Owning organization |
| `createdAt` | `string` | ISO timestamp of original creation |
| `ingestedAt` | `string` | ISO timestamp of ingestion |
| `permissions` | `DocumentPermissions` | Visibility and access control |
| `version` | `string` | Document version |
| `hash` | `string` | Content hash for dedup and cache invalidation |
| `metadata` | `Record<string, unknown>` | Arbitrary source-specific metadata |

### Permissions

```typescript
interface DocumentPermissions {
  visibility: 'public' | 'organization' | 'private' | 'restricted';
  allowedUserIds: string[];
  allowedRoleIds: string[];
}
```

## Creating Documents

The `createDocument()` helper builds an `IngestedDocument` with sensible defaults:

```typescript
import { createDocument } from '@compilerai/enterprise-rag';

const doc = createDocument(
  'github',                              // source
  'repo-42/issue-7',                     // sourceId
  'Bug: search timeout',                 // title
  'Search requests time out after 30s.', // content
  'bob',                                 // author
  'org-1',                               // organizationId
  { visibility: 'restricted', allowedRoleIds: ['engineers'] }, // permissions (optional)
  { repository: 'compilerai/core' },     // metadata (optional)
);
```

Defaults: `visibility` is `'organization'`, `allowedUserIds` and `allowedRoleIds` are empty arrays, `version` is `'1'`, `createdAt` and `ingestedAt` are set to the current ISO timestamp, and `hash` is computed from the content.

## Ingestion via RAGEngine

The public API ingests documents through `RAGEngine.ingest()`, which handles registration, chunking, embedding, and indexing in one call:

```typescript
import { RAGEngine, createDocument } from '@compilerai/enterprise-rag';

const rag = new RAGEngine();
const result = await rag.ingest('github', [
  createDocument('github', 'issue-7', 'Bug: search timeout', '...', 'bob', 'org-1'),
]);

console.log(result);
// { documentsIngested: 1, chunksCreated: 3, embeddingsGenerated: 3, errors: [], durationMs: 12 }
```

Upsert semantics: if a document with the same ID already exists and its content hash has changed, it is updated; otherwise it is skipped.
