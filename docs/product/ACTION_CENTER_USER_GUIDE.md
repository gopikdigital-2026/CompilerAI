# Action Center User Guide

## What is the Action Center?

The Action Center is your centralized hub for managing all actions generated by CompilerAI. Every opportunity detected by the AI can be converted into an executable, traceable action with full history, comments, assignments, and notifications.

## Getting Started

### Opening the Action Center
1. Click **"Action Center"** in the left sidebar navigation.
2. You'll see a dashboard with summary widgets and a list of all actions.

### Dashboard Widgets

| Widget | Description |
|--------|-------------|
| Open Actions | Actions not yet completed or cancelled |
| Critical | Open actions with critical priority |
| Completed | Actions that have been finished |
| Expected ROI | Total ROI value from completed actions |
| Avg Resolution Time | Average days from creation to completion |

## Converting Opportunities to Actions

### From the Analysis Page
1. Run an analysis to detect opportunities.
2. On any opportunity card, click **"Convert to action"**.
3. The opportunity is automatically converted to an action with all metadata preserved.
4. You'll be navigated to the Action Center to see the new action.

### What Gets Preserved
- Title and description from the opportunity
- Priority (calculated from impact, confidence, effort, time, dependencies, risk)
- Expected impact and ROI
- Impact, urgency, effort, risk levels
- Dependencies
- Link to the original opportunity (traceability)

## Managing Actions

### Changing Status
1. Click on any action card to open the detail modal.
2. In the **Overview** tab, find the "Change status" section.
3. Click one of the available status buttons (only valid transitions are shown).
4. Optionally add a comment explaining the change.
5. Click **Confirm**.

### Updating Progress
1. Open the action detail modal.
2. In the **Overview** tab, use the progress slider (0-100%).
3. Setting progress to 100% automatically marks the action as completed.

### Assigning a Responsible Person
1. Open the action detail modal.
2. In the **Overview** tab, find the "Responsable" section.
3. Select a team member from the dropdown.
4. Click **Assign**.

### Changing Priority
1. Open the action detail modal.
2. In the **Overview** tab, find the "Prioridad" section.
3. Select a new priority from the dropdown.
4. Click **Cambiar**.

## History and Comments

### Viewing History
1. Open the action detail modal.
2. Click the **History** tab.
3. See a chronological timeline of all changes (status, assignments, priority, progress).

### Adding Comments
1. Open the action detail modal.
2. Click the **Comments** tab.
3. Type your comment in the input field.
4. Press Enter or click the send button.

## Notifications

### Viewing Notifications
1. Click the **bell icon** in the Action Center header.
2. See all notifications (action created, priority changed, assignee changed, completed, blocked).
3. Unread notifications have a blue indicator.

### Marking as Read
- Click any notification to mark it as read.
- Click **"Marcar todas como leídas"** to mark all as read.

## Filtering and Search

### Status Filters
Use the status filter buttons to show: All, Pending, Assigned, In Progress, Blocked, or Completed actions.

### Priority Filters
Use the priority filter buttons to show: All, Critical, High, Medium, or Low priority actions.

### Search
Use the search box to find actions by title.

## Blockers

When actions have blockers (uncompleted dependencies, no progress, overdue deadlines), a red alert banner appears at the top of the Action Center listing the blocked actions and their reasons.

## Permissions

| Role | View | Create | Update | Delete |
|------|------|--------|--------|--------|
| Owner | Yes | Yes | Yes | Yes |
| Admin | Yes | Yes | Yes | No |
| Member | Yes | Yes | Yes | No |
| Viewer | Yes | No | No | No |

## Traceability

Every action maintains a link to its original opportunity. You can see the opportunity title in the action card and in the detail modal's overview tab. This ensures full traceability from detection to execution.
